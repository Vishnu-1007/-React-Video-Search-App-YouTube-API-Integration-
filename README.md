# 🎬 React Video Search App (YouTube API Integration)

## 🔍 Overview

A responsive video search platform built with React that integrates the YouTube Data API to fetch and display real-time videos based on user search queries.

This project demonstrates API integration, asynchronous data handling, reusable components, and modern UI development.

## 🚀 Features

✔ Search videos dynamically using YouTube API  
✔ Real-time results fetching  
✔ Pagination / Load more functionality  
✔ Responsive video grid layout  
✔ Clean reusable React components  
✔ Error handling and loading states

## 🧠 Tech Stack

- React (Hooks)
- JavaScript (ES6+)
- YouTube Data API
- CSS / Tailwind / Bootstrap
- Axios / Fetch API

## ⚙️ How to Run Locally

1. Clone the repository
   https://github.com/Vishnu-1007/youtube.git
   
3. Install dependencies
   npm install

4. Start the app
   npm start
